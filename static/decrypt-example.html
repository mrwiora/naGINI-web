🔓 Nagini Script Decryption

This page demonstrates how to decrypt and view scripts that were encrypted with AES-256-GCM before publishing. Enter the encrypted content and your passphrase to decrypt the script.

⚠️ Security Notice: This is a client-side decryption tool. Your passphrase never leaves your browser. The decryption happens entirely on your machine using the Web Crypto API.

Decrypt Encrypted Script

Usage Instructions

How to use this decryption tool:
  1. Copy the encrypted base64 content from the published script
  2. Paste it into the "Encrypted Content" field above
  3. Enter the same passphrase you used when encrypting
  4. Click "Decrypt" to view the original script content

Command-Line Decryption Example

If you need to decrypt and execute a script from the command line, you can use this approach: 

# Fetch the encrypted content and decrypt it with the Node.js script below
curl -s https://YOUR-SERVER/SHORTID > encrypted.txt
read -rs NAGINI_PASSPHRASE && export NAGINI_PASSPHRASE
node decrypt.js encrypted.txt

Node.js Decryption Script

Here's a Node.js script example for decrypting Nagini scripts: 

const crypto = require('crypto');
const fs = require('fs');

// Supports format v2 ("NGN" 0x02 header, 600k iterations, header as AAD)
// and the legacy headerless format (100k iterations).
function decrypt(encryptedBase64, passphrase) {
    let data = Buffer.from(encryptedBase64.trim(), 'base64');

    const header = Buffer.from([0x4e, 0x47, 0x4e, 0x02]);
    let iterations = 100000;
    let aad = null;
    if (data.subarray(0, 4).equals(header)) {
        iterations = 600000;
        aad = header;
        data = data.subarray(4);
    }

    const salt = data.subarray(0, 16);
    const iv = data.subarray(16, 28);
    const authTag = data.subarray(-16);
    const ciphertext = data.subarray(28, -16);

    const key = crypto.pbkdf2Sync(passphrase, salt, iterations, 32, 'sha256');
    const decipher = crypto.createDecipheriv('aes-256-gcm', key, iv);
    if (aad) decipher.setAAD(aad);
    decipher.setAuthTag(authTag);

    return Buffer.concat([decipher.update(ciphertext), decipher.final()]).toString('utf8');
}

// Usage: node decrypt.js <file-with-encrypted-content>
// The passphrase is read from NAGINI_PASSPHRASE so it does not appear in the process list.
const encryptedContent = fs.readFileSync(process.argv[2], 'utf8');
const passphrase = process.env.NAGINI_PASSPHRASE || '';

try {
    process.stdout.write(decrypt(encryptedContent, passphrase));
} catch (error) {
    console.error('Decryption failed:', error.message);
    process.exit(1);
}

Bash One-Liner Example

# Decrypt, review, then execute (use with caution!)
node decrypt.js encrypted.txt > script.sh
less script.sh
bash script.sh
⚠️ Security Warning: Only decrypt and execute scripts from trusted sources. Always review the decrypted content before execution. AES-GCM detects tampering by anyone who does not know the passphrase, but it cannot tell you who wrote the script, and a compromised server can alter this page and the composer that performs the encryption.
